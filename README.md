# Повторения — интервальное повторение слов

Мобильное приложение (Android и iPhone) для заучивания слов блоками по методу интервальных повторений.

## Как это работает

1. **Добавьте блок** — например «Слова 1–10». Можно задать диапазон номеров и сразу разбить его
   на части: «с 1 по 100 по 10» создаст 10 блоков, по одному на каждый день.
2. **Выучили — нажмите ✓.** С этого дня приложение само распланирует повторения
   по интервалам (по умолчанию: 1, 3, 5, 7, 10, 14, 21, 30, 60 дней).
3. **Каждый день открывайте вкладку «Сегодня»** — там список того, что нужно выучить
   и что повторить. Повторили — нажмите ✓, блок уйдёт на следующий интервал.

Вкладки:

- **Сегодня** — что выучить и что повторить сегодня (просроченное подсвечивается).
- **План** — все будущие изучения и повторения по датам.
- **Все блоки** — список блоков с прогрессом и поиском.
- **Настройки** — редактирование интервалов (добавить/удалить любой), способ отсчёта
  (от даты изучения или от предыдущего повторения), резервная копия данных.

У каждого блока можно открыть карточку: поменять название, записать сами слова,
поправить дату изучения, задать свои интервалы, отменить последнее повторение или удалить блок.

Данные хранятся только на телефоне. Для переноса на другое устройство используйте
«Настройки → Резервная копия».

## Установка на Android

Каждый push в репозиторий автоматически собирает APK (GitHub Actions, workflow «Android APK»).

1. Откройте на телефоне страницу репозитория → **Releases** → последняя сборка.
2. Скачайте `povtoreniya.apk` и откройте его. Если телефон спросит — разрешите установку
   из этого источника.

## iPhone

Код общий (Expo / React Native), приложение уже работает на iOS. Для установки на iPhone нужен
аккаунт Apple Developer ($99 в год); сборка делается через EAS:

```bash
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios
```

Для быстрой проверки без публикации: установите на iPhone приложение **Expo Go**, запустите
`npm start` на компьютере и отсканируйте QR-код.

## Разработка

```bash
npm install
npm start          # dev-сервер Expo (Expo Go / эмулятор)
npx tsc --noEmit   # проверка типов
npx expo lint      # линтер
```

Структура:

- `src/app/` — экраны (Expo Router): `(tabs)/` — вкладки, `add.tsx` — добавление, `item/[id].tsx` — карточка блока.
- `src/lib/schedule.ts` — расчёт расписания повторений.
- `src/lib/store.tsx` — состояние приложения и действия; `src/lib/storage.ts` — сохранение на устройстве.
- `src/components/` — общие UI-компоненты.
